## 历史排查档案与技术约束

### 1. 尝试本地扫描与云端合并导致列表反复闪烁与崩溃
- **现象**：早期尝试在本地扫描已有文件与云端列表做 Merge，导致用户进入列表页时列表频繁跳动，大文件夹下直接内存溢出。
- **根因分析**：
  - 移动端本地文件 IO 在包含数百个 Markdown 文件时开销巨大，且两端文件名大小写与特殊字符处理策略不一致，引发竞争。
- **必须保持的技术约束**：
  - 恪守“列表即菜单”原则，文件列表完全以云端 `listFiles()` 为准，本地仅做首屏快照缓存，杜绝全盘扫描。
