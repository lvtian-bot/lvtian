# 动态剪藏与摘要

绿天 App 的底部「动态」标签浏览 Web Clipper 归档。卡片以摘要首个非空行作为标题，沿用 Telegram 的 Markdown 标题处理方式。点标题打开 YAML `source` 对应的原文链接，链接按 Telegram 发布规则移除查询参数和片段。余下的 Markdown 作为正文，保留正文中的发布时间。空摘要仍显示卡片，可通过「重写」生成摘要。

卡片底部左侧显示相对剪藏时间。剪藏时写入的 YAML `created` 用于显示和排序，缺失或无效时回退到文件创建时间。服务端按这个时间排序，再按归档 ID 确定同一时刻的顺序。向下滚动分页读取历史。

App 在本地保存当前配对连接最近成功加载的第一页和刷新时间。重开 App 或重新进入「动态」时先显示本地列表。首次没有缓存会请求列表。有缓存时，距上次成功刷新满五分钟，且「动态」在前台，才会在进入标签或 App 恢复前台时自动刷新。下拉可立即刷新。顶部小转圈不拦截手势，失败时保留已有列表。离开标签或进入 App 后台会取消正在进行的列表请求。已在「动态」时再点底部标签，只滚回顶部。

## 重写与删除

「重写」沿用 [Web Clipper 已实现的摘要接口](https://github.com/lvtian-bot/web-clipper/pull/12)。它以现有正文为输入，只替换摘要区块，保存后用原远程路径上传。若坚果云原位置的同名文件已不存在，仍按原路径上传。旧归档在无法确认原上传位置时停止重写。

「删除」先确认，再由 Web Clipper 删除工作区里的整篇归档。坚果云只处理该文章原上传目录中的同名文件。如果该文件已不存在或移走，原路径返回缺失即完成。其他目录的文件不会被查找或删除。本地删除成功后立即移除卡片，若云端删除失败则提示结果。

[Web Clipper PR #10](https://github.com/lvtian-bot/web-clipper/pull/10) 曾将另一目录的成品复制到工作区，同名归档的后缀可能只存在于本地。后续 [PR #11](https://github.com/lvtian-bot/web-clipper/pull/11) 将剪藏、摘要和上传统一到工作区内同一文件，[PR #13](https://github.com/lvtian-bot/web-clipper/pull/13) 按文件名覆盖。默认上传目录为 `nascence/Collection/`。工作区的年、月不进入坚果云路径。Web Clipper 通过上传记录或可确认的历史规则定位原文件。

## 服务端接口

绿天服务端根据实际启动配置读取工作区的 `moments/YYYY/MM/`。`GET /api/moments` 接受上一页的 `cursor`，返回剪藏时间、摘要、原文链接及操作所需的版本。App 不下载文章全文。

绿天通过 `LVTIAN_WEB_CLIPPER_API_URL` 读取 Web Clipper 的本机回环 origin，通过 `LVTIAN_WEB_CLIPPER_API_TOKEN` 使用 Bearer 鉴权。两服务指向同一归档根。未配对时仍可浏览。重写走 `POST /api/moments/summary`，请求包含 `id`、`revision` 和 `action: "regenerate"`。Web Clipper 返回 `uploaded` 或 `upload_failed` 后，绿天重读本地卡片。

### Web Clipper 整篇删除契约

绿天已接入 `POST /api/moments/delete`。Web Clipper 需提供同路径的本机接口和现有 Bearer 鉴权。请求包含 `id`（`YYYY/MM/文件名.md`）与 `revision`（完整归档的 SHA-256 十六进制值）。

1. Web Clipper 在归档根下重新校验路径、文件类型和版本，采用首传、上传重试与重写共用的文件锁。在锁内阻止待处理的旧上传在删除后重新创建云端文件。
2. 删除本地整篇归档。若可确认原上传目标，仅向该目标尝试删除。原路径返回 404 或 410 视为云端已无该文件。确知归档只保存在本地时，只删除本地文件。若旧归档的原上传位置有歧义，删除本地文件后报告云端删除失败，无需发起云端请求。
3. 本地与云端处理完成返回 HTTP 200 和 `{"status":"deleted"}`。本地已删除但远端删除失败或目标无法确认时返回 HTTP 200 和 `{"status":"delete_failed"}`。文件不存在、版本冲突、本地删除失败等情况返回非 2xx，绿天保留卡片并提示失败。

Web Clipper 配套接口上线前，已配对的绿天可以重写；整篇删除会报告失败并保留文件。删除接口由 Web Clipper 实现，因为该服务持有原上传路径、坚果云凭据及上传重试使用的文件锁。
