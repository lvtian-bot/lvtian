# 故障排查与速查手册

> 本文档汇总绿天在开发、测试及生产运行中的全链路排查方案与常见错误码速查表。

---

## 1. 常见故障排查步骤

### 1.1 Android 构建与原生异常排查
- **Prebuild 后启动闪退**：
  1. 检查 `android/gradle.properties` 是否存在配置冲突。
  2. 检查 `plugins/` 目录下的 Config Plugins 是否语法报错或未正确返回 config。
  3. 执行 `npx expo prebuild --clean` 重新生成原生目录。
- **Keystore 签名异常**：
  1. 确认 `keystore/simplejournal.keystore`（或对应签名文件）路径正确。
  2. 验证凭据环境变量或 `plugins/withKeystore.js` 中的别名与密码配置。

### 1.2 编辑器修改未生效排查
1. 检查是否执行了 `npm run build:editor`。
2. 检查 `src/editor-web/editorHtml.ts` 的最后修改时间是否更新。
3. 执行 `npx expo start -c` 清除 Metro 缓存。

### 1.3 状态与持久化排查
- **设置未持久化**：
  - 检查是否在 Store Hydrate 完成前读取了初始状态。
  - 敏感凭据（如 SecretKey）需检查 `expo-secure-store` 权限与存储状态。
- **FileMetadata 丢失**：
  - 检查 `useFileMetadataStore` 的 AsyncStorage 持久化键值，确认未在清除缓存时被误删。

## 2. 常见错误代码速查表

| 错误代码 / 标识 | 常见触发场景 | 根因定位 | 标准处理策略 |
|---------------|-------------|---------|-------------|
| `412 Precondition Failed` | 云端文件上传 | ETag 不匹配，远端已被其他设备修改 | 标记 `conflict-failed`，触发 Stage 2 三路合并救援 |
| `401 Unauthorized` | WebDAV 连接 | 账号密码错误或坚果云未开启“应用授权密码” | 提示用户检查凭据并在坚果云后台生成专属密码 |
| `404 Not Found` | 获取云端文件 HEAD | 云端尚未创建该文件 | 属于正常初次同步场景，自动转为上传创建 |
| `NETWORK_TIMEOUT` | 网络弱网/断流 | 请求超过设定的 15/20 秒阈值 | 中断当前检查，回退为离线/等待重试，防止 UI 死锁 |
| `JSON_PARSE_ERROR` | 读取本地元数据 | 本地存储文件损坏 | 捕获异常，重置损坏的条目并记录警告日志 |

## 3. 日志收集与诊断流程

1. **开启调试日志**：在开发环境下，`FileSystemService` 与 `SyncService` 输出带有前缀 `[SyncService]`、`[FS]`、`[Cloud]` 的控制台日志。
2. **WebView 控制台桥接**：CodeMirror 内部日志通过 Bridge 派发 `LOG` 事件，在 React Native 端统一通过 `console.log` 打印，排查编辑器内部交互异常。
