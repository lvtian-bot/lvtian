## 历史排查档案与技术约束

### 1. 本地 EAS Build 构建命令超时或挂死
- **现象**：在 Windows 上运行 `eas build --platform android --profile preview --local` 时卡在 Gradle 下载阶段。
- **根因分析**：
  - 本地网络访问 Gradle 官方分发源缓慢或被拦截。
- **必须保持的技术约束**：
  - 遇到该问题时，可在 `android/gradle/wrapper/gradle-wrapper.properties` 临时切换镜像或设置国内代理，并在本地缓存好 Gradle 运行时。
