# MDNote 编译与真机测试规范

> 本文档规范 Windows 平台下的 MDNote 开发环境配置、工具链分层、构建命令与关键环境约束。

---

## 1. 环境架构总览

环境分为四层体系：

### ① Node 侧（运行 Expo CLI、Metro 与 Vite 构建）
| 组件 | 推荐版本 | 说明 |
|------|---------|------|
| **Node.js** | LTS v20+ (实测 v20/v24 均可) | JavaScript 运行时 |
| **npm / pnpm** | npm v10+ / pnpm | 包依赖管理器 |
| **Expo SDK** | 57.x (当前 57.0.22/57.0.24) | 跨平台移动端应用框架 |
| **React Native / React** | 0.86.3 / 19.2.3 | 原生移动运行时与 UI 库 |

### ② JDK 与 Java 侧
| 组件 | 说明 |
|------|------|
| **JDK 17** | 唯一 JDK：Microsoft OpenJDK 17.0.20（winget 系统级安装于 `C:\Program Files\Microsoft\jdk-17.0.20.101-hotspot`），既运行 Gradle，也命中 RN 构建要求的 `jvmToolchain(17)`；与 GitHub release.yml 构建环境（Java 17）及 Expo 官方推荐一致 |
| **JAVA_HOME** | 系统级环境变量，MSI 安装时自动指向上述 JDK 17 目录，勿指向 Android Studio 自带的 JBR |

### ③ Android SDK 侧
| 组件 | 版本/路径 | 说明 |
|------|-----------|------|
| **compileSdk / targetSdk** | 36 (Android 15 / 16) | 与 Expo SDK 57 及 RN 0.86 统一 |
| **minSdk** | 24 (Android 7.0+) | 兼容绝大多数现代 Android 设备 |
| **ANDROID_HOME** | `C:\Users\<User>\AppData\Local\Android\Sdk` | 包含 `platform-tools`, `build-tools`, `platforms` |

### ④ 编辑器混合构建工程
| 组件 | 路径 | 构建命令 |
|------|------|---------|
| **CodeMirror 6 嵌入工程** | `src/editor-web/` | `npm run build:editor` |
| **构建原理** | Vite + `viteSingleFile` 单文件打包成 HTML，通过 `generate-html.js` 转义注入 `src/editor-web/editorHtml.ts` |

## 2. 核心日常工作流命令

| 场景 | 命令 | 详细说明 |
|-----|------|---------|
| **依赖安装** | `npm install` 或 `npx expo install` | 安装项目所有依赖 |
| **启动 Metro 服务** | `npx expo start` | 启动开发服务器（支持局域网或 Tunnel 调试） |
| **重新预构建原生** | `npx expo prebuild --clean` | 修改 `app.config.js` 或自定义插件后必须重跑 |
| **本地 Android Debug 运行** | `npx expo run:android` | 直接构建并部署到连接的真机/模拟器 |
| **构建 Web 编辑器** | `npm run build:editor` | 修改 `src/editor-web/` 下任何文件后必须执行 |
| **本地打包（备用）** | prebuild ＋ gradle 直构 | Windows 上 `eas build --local` 不可用（仅 Linux/macOS），流程与坑位见用户级技能 `expo-app-release` |
| **代码静态类型检查** | `npx tsc --noEmit` | 静态类型检查，修改代码后推荐运行 |
| **清理构建与重置缓存** | `npx expo start -c` | 清除 Metro 缓存启动 |

## 3. 重要环境约束与备忘

1. **严禁直接修改 `android/` 目录**：
   - 项目采用 Expo Prebuild 模式，`android/` 属于构建产物。任何 Manifest、Gradle 配置或权限调整，必须通过 `plugins/` 目录下的 Config Plugin 并在 `app.config.js` 中声明。
2. **编辑器双向生效机制**：
   - 仅仅修改 `src/editor-web/index.ts` 不会在应用中立即体现！必须执行 `npm run build:editor` 生成新的 `editorHtml.ts`，并重载应用。
3. **PowerShell 脚本执行策略**：
   - Windows 下若遇到 `ps1` 脚本无法加载，需以管理员权限设置：`Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned`。
4. **本地打包版本号一致性**：
   - `android/` 是 prebuild 生成的本地产物，不随发版自动更新。本地构建或真机部署前须比对 `app.config.js` 与 `android/app/build.gradle` 的版本号，不一致时先执行 `npx expo prebuild --clean` 重新生成，避免打出低于已装正式版的旧包。
