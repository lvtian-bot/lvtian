# 闪念键盘避让问题记录

## 当前结论

Android 弹窗的窗口高度可能在键盘弹出后保持原值。快速录入面板依据键盘高度和窗口实际缩小量计算底部避让。自动化测试覆盖了窗口未缩小、部分缩小、等量缩小和键盘收起。Android 真机仍需核对布局。

## 2026-11-26 输入面板被键盘遮挡

- 现象：Android 0.3.7 接收闪念样式热更新后，点击新建闪念，系统键盘自动出现，录入面板没有随之上移。输入区的两行初始高度也不足以写一小段文字。
- 根因：提交 `555045a` 移除了 Android 的键盘高度补偿，外层容器依赖原生弹窗缩小。此前的 Expo 迁移修复 `9cb5584` 已用键盘事件补偿过同一现象。
- 处理：恢复键盘事件驱动的底部避让，在原生弹窗已缩小时扣除对应高度。正文区参考白底样式 `101e29e` 恢复八行初始高度，空间不足时允许正文收缩，底部仍保留操作区。
- 真机验收：从闪念页及系统分享打开面板，核对键盘弹出、收起、切换输入法和长文录入时的正文区、展开入口及保存箭头。
