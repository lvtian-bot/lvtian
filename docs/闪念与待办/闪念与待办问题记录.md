## 历史排查档案与技术约束

### 1. 手动编辑后时间格式轻微偏差导致时间线断裂
- **现象**：用户在 PC 端通过其他 Markdown 编辑器手动编辑了 `flash_notes.md`，导致移动端解析时部分条目丢失。
- **根因分析**：
  - 原解析正则未考虑毫秒、少写秒数或多空格（例如 `## 2025-01-19 14:30`）。
- **必须保持的技术约束**：
  - `FlashNoteService` 生成的时间戳必须严格填充前导零（保证 `YYYY-MM-DD HH:mm:ss` 19位长度）。
  - 解析器的正则应具备容错性，对单空格或无秒数格式做向下兼容，并在下次规范写入时对齐标准格式。
