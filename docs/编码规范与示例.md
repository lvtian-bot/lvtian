# 绿天 (Lvtian) 编码规范与核心示例

> 本文档规范绿天移动端的组件开发、逻辑复用、架构分层要点，并提供核心业务扩展的参考代码范式。

---

## 1. 架构与编码核心规范

### 1.1 组件开发规范
- **函数式与 Hooks**：全面采用函数式组件与 Hooks，严禁使用 Class 组件。
- **样式规范**：统一使用 `StyleSheet.create` 管理样式，避免滥用内联样式对象触发重复渲染。
- **国际化规范**：所有可见文本必须使用 `useTranslation` 从 `src/locales/` 获取，禁止硬编码。
- **类型安全**：严格遵循 TypeScript 严格模式，严禁使用 `any`，所有 Props、State 和函数必须有完备的 Interface / Type 定义。

### 1.2 逻辑下沉与 DRY 原则 (Don't Repeat Yourself)
- **禁止在 UI 重复编写业务**：UI 组件（如 `FlashScreen`, `TodoScreen`, `PreviewScreen`）只负责状态呈现与用户交互事件分发，严禁直接调用底层的网络、哈希比对、文件写入。
- **服务层是业务唯一源头**：
  - 云端相关操作必须通过 `CloudService`（调用前必检 `isConfigured()`）。
  - 文件读写必须通过 `FileSystemService`。
  - 同步流转必须下沉至 `SyncService` 或 `FlashNoteService`。
- **状态读取规则**：
  - UI 组件内部使用 Hook：`const status = useSyncStore(s => s.syncStatus);`
  - Service 业务逻辑内部使用纯函数读取：`const status = useSyncStore.getState().syncStatus;`

### 1.3 性能优化要点
1. **避免不必要的文件 IO**：在需要判断文件存在或大小时，优先读取内存中的 `FileMetadata`，避免频繁调用 `FileSystem.getInfoAsync`。
2. **批量操作聚合**：多次状态更新（如待办列表勾选）应在内存中先更新状态对象，防抖后再统一写盘与入队。
3. **大文件防爆**：对于超过 5MB 的图片或附件，避免使用 Base64 转码传输，优先使用流式下载或直传通道。

### 2.2 跨组件同步 Hook 范式 (useCloudSync)
```typescript
import { useEffect, useState } from 'react';
import { useSyncStore } from '../store/useSyncStore';
import { SyncService } from '../services/SyncService';

export function useCloudSync(filePath: string) {
  const [isSyncing, setIsSyncing] = useState(false);
  const syncStatus = useSyncStore((state) => state.fileStatuses[filePath] || 'idle');

  const triggerSync = async () => {
    setIsSyncing(true);
    try {
      await SyncService.syncSingleFile(filePath);
    } finally {
      setIsSyncing(false);
    }
  };

  return {
    isSyncing,
    syncStatus,
    triggerSync,
  };
}
```

### 2.3 状态管理 Store 范式 (Zustand)
```typescript
import { create } from 'zustand';
import { persist, createJSONStorage } from 'zustand/middleware';
import AsyncStorage from '@react-native-async-storage/async-storage';

interface ExampleState {
  data: string[];
  addItem: (item: string) => void;
  clear: () => void;
}

export const useExampleStore = create<ExampleState>()(
  persist(
    (set, get) => ({
      data: [],
      addItem: (item) => set({ data: [...get().data, item] }),
      clear: () => set({ data: [] }),
    }),
    {
      name: 'example-storage',
      storage: createJSONStorage(() => AsyncStorage),
    }
  )
);
```
