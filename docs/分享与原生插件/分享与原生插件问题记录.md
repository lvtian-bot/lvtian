## 历史排查档案与技术约束

### 1. React Native 新架构下 Android 热启动首次分享失败
- **现象**：在启用新架构 (`newArchEnabled=true`) 后，从其他应用分享内容到 MDNote，热启动状态下无法将分享内容传递到 JavaScript 层，甚至抛出 `IllegalStateException: Cannot get ReactInstanceManager without a ReactNativeHost`。
- **演进与排查历程**：
  1. *第一阶段尝试*：在 `MainActivity.kt` 访问 `reactInstanceManager?.currentReactContext`，直接抛出 `IllegalStateException`（新架构已废弃该 API）。
  2. *第二阶段尝试*：改用 `reactNativeHost?.reactInstanceManager?.currentReactContext`，触发新架构告警 `You should not use ReactNativeHost directly in the New Architecture`，且 ReactContext 在 30 次重试内始终为空。
  3. *第三阶段根治*：调研 React Native 官方迁移方案（PR #47659），新架构推荐使用 `reactActivityDelegate?.getCurrentReactContext()`。
- **必须保持的技术约束**：
  - 在 `MainActivity.kt` 中获取 ReactContext 时，必须严格使用官方推荐的委托方法：
    ```kotlin
    val reactContext = reactActivityDelegate?.getCurrentReactContext()
    ```
  - 当 context 尚未就绪时，必须具备内存挂起缓冲机制 (`pendingShareText`) 配合 `retryShareEvent()` 轮询重试（每 100ms 重试一次，上限 30 次），确保冷启动和热启动均能稳妥投递。
