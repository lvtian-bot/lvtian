# 分享扩展与原生插件配置

> 本文档规范跨应用文本/文件分享接收机制、Expo Config Plugins 的编写与原生构建定制约束。

---

## 1. 跨进程分享接收机制

绿天支持从外部应用（浏览器、微信、社交软件等）直接分享 Markdown 文本或链接至应用：

### 1.1 事件链路与状态流转
```text
[外部应用分享发送]
       │ (Intent: ACTION_SEND)
       ▼
[Android 原生层 MainActivity]
       │
       ▼ (DeviceEventEmitter 广播: SHARE_RECEIVED_EVENT)
[React Native JS 运行环境]
       │
       ▼ (useShareStore 接收解析)
[弹窗提示追加至闪念笔记或新建文件]
```

### 1.2 通信协议与数据结构
`SHARE_RECEIVED_EVENT` 传递标准数据负载：
```typescript
interface SharePayload {
  type: 'text' | 'file';
  value: string; // 纯文本或本地 URI
  extraTitle?: string;
}
```

## 2. 原生 Config Plugins 治理规范

### 2.1 铁律：禁止修改 `android/`
任何针对 Android 原生工程的修改（如 Gradle 配置、Manifest 权限、Keystore 签名、主题手势等），**必须编写在 `plugins/` 目录中，并在 `app.config.js` 引用生效**。

### 2.2 核心插件清单
1. **`plugins/withKeystore.js`**：负责在 Gradle 构建时自动注入生产发版签名密钥。
2. **`plugins/withDisablePredictiveBack.js`**：针对 Android 14+ 禁用原生预测性返回手势，防止手势冲突导致编辑器异常关闭。
