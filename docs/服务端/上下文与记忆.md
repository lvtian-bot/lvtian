# 上下文与记忆

## 职责与边界

本模块负责个人主聊天的固定系统规则、工作区档案加载和记忆维护约定。指令复用 OpenClaw 官方启动与记忆段落，中文适配、固定上游提交与许可证见 [来源说明](../../server/prompts/openclaw/来源说明.md)。

模型通过 DSH 已有文件工具判断和写入记忆。服务端不截取回复写日记，不运行额外的长期记忆提炼模型，不创建记忆整理日程。会话轮换的 `pending_background.txt` 是接力材料，继续由 [会话轮换设计](设计/基于人脑记忆模型的会话轮换设计.md) 管理，不自动归入长期记忆。

## 代码与数据归属

| 入口 | 职责 |
|---|---|
| `server/prompts/openclaw/记忆与上下文指令.md` | 随程序维护的固定指令，不在 App 提供编辑入口 |
| `server/src/workspaceContextPlugin.ts` | 通过 DSH `systemPrompt.section` 注册固定系统指令，通过 `systemPrompt.context` 注册动态工作区快照 |
| `server/src/workspaceContext.ts` | 白名单读取、日期选择、长度预算、文件状态与截断提示 |
| `server/src/workspaceContextConfig.ts` | 生成项目持有的 ACP 插件配置，不改用户 profile；已有内容冲突则明确失败 |
| `server/src/memoryManager.ts` | 初始化缺失的三个基础档案和 memory 目录，保留已有内容及历史日记 |
| `server/src/acpEngineManager.ts` | 转交原始用户输入、会话接力和旧上下文绑定迁移，不负责读取档案 |
| `server/src/sessionManager.ts` | 持久化底层会话绑定的 `workspaceContextVersion`，包括事件重放和快照轮换 |

工作区是档案与记忆唯一来源；DSH 会话历史保留已提供的快照。App 聊天记录不额外复制固定提示词与档案。插件配置位于 `<dataDir>/context/acp-context-<内容哈希>.patch.yml`，只包含项目插件路径和工作区路径，不包含凭据。工作区或安装路径变化时生成对应的新配置，不覆盖旧配置。

## 文件职责

| 文件 | 用途与加载 |
|---|---|
| `AGENTS.md` | 用户工作区规范；由 DSH 原生指令插件发现与刷新，不重复注入，也不自动修改 |
| `SOUL.md` | 人设、语气和行为边界 |
| `IDENTITY.md` | 可选身份档案，只加载既有文件，不自动创建 |
| `USER.md` | 稳定偏好及个人背景；条目标记观察日期和 active/superseded 状态 |
| `BOOTSTRAP.md` | 可选首次引导，只加载既有文件，完成后按授权处理 |
| `MEMORY.md` | 精简的长期事实和决定 |
| `memory/YYYY-MM-DD.md` | 每日详细背景；按服务端本地日历自动加载今天和昨天，更早记录按需查找读取 |

模型写入前先读原文件，优先局部更新；更正偏好时不保留矛盾的有效指令。没有值得保留的内容就不写入，不向记忆文件保存凭据。用户对 AGENTS.md、技能或人设文件的修改限制继续生效。

## 装配与刷新

1. 服务端启动时准备独立 ACP 配置，与已有任务工具配置一同挂载插件。
2. DSH 装配请求时取得固定系统指令和当前文件快照。固定指令处于 system 角色；档案处于 DSH 带来源的动态上下文，独立于用户原始提问。
3. 固定版本 `0.2.2-rc.1` 会比较动态上下文与已保留快照；相同内容不重复加入历史，发生变化时追加新快照。新快照明确取代同文件旧版本，旧快照仍可能存在于历史中，不宣称历史字节已经删除。
4. 外部编辑、模型工具写入、文件删除、清空及本地日期变化，会在后续模型步骤重新装配时生效。压缩移除当前快照后，DSH 在下一步重新提供；恢复会话时依据保留的会话投影对账。
5. 固定指令随程序版本加载。修改指令资源后需重启 ACP 引擎；用户工作区文件修改无需重启。

文件读取上限为 1 MiB；以非阻塞方式打开并检查描述符，避免 Linux 命名管道阻塞代理。非普通文件、越出工作区的真实路径、无效 UTF-8 和读取失败均以明确状态报告，不能解释为没有相关记忆。自动加载不扫描其他目录。

单文件默认 20,000 字符，USER.md 最大 4,000 字符，快照总量含标题和标记不超过 60,000 字符。截断保留约 75% 开头和 25% 末尾，避免切断 Unicode 字符，标记要求按需读取原文件；磁盘原文不变。

## 会话范围与权限

插件仅挂载于个人聊天 ACP 根会话。子代理不自动注入个人档案；原生自动任务的独立 web profile 不安装该插件。该选择只是上下文注入范围，不是文件系统权限屏障，也不会清除主动 fork 所继承的父会话历史。工具可访问范围仍由 DSH 实际权限和审批控制。

## 升级迁移

旧会话曾将档案全文重复写进用户消息。已有绑定缺少当前 `workspaceContextVersion` 时，首次请求先登记接力未完成、解除旧绑定，并通过原有接力路径提供已有摘要及近期原文，新建干净底层会话。新绑定保存上下文版本；失败时保留接力状态，下次继续，不重复迁移已完成的新绑定。App 聊天历史与用户文件不清理。

## 验证范围

- `workspaceContext.test.mjs`：文件加载、修改/删除/清空、日期、预算、UTF-8、正式组装接口、子代理范围和配置冲突。
- `workspaceContextDsh.test.mjs`：真实 DSH 循环与真实 ACP 子进程挂载，本地合成模型适配器；检查实际请求角色、独立用户输入、未变去重、变化刷新和投影压缩后的快照恢复，不调用外部模型。
- `cognitiveSessionRotation.test.mjs`：原始用户输入、取消机械日记、旧会话迁移及已有接力回归。

上述自动测试不等于真实模型对所有记忆规则的遵守保证；生产模型主动记录的内容质量仍需实际使用验证。

Windows 本地全量回归存在既有的报告持久化失败：`persistDurableMessage` 对只读打开的文件执行 `fsync` 返回 `EPERM`，连带影响报告投递用例。已用本次变更前的 SessionManager 源码独立复现；本模块未修改该持久化屏障。全量结果需同时核对 Linux CI，不以局部测试替代。
