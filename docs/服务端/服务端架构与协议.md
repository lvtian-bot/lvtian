# 服务端架构与通信协议

## 1. 模块定位与职责

绿天（Lvtian）独立服务端位于仓库 `server/` 目录下，负责在用户的 Windows 或 Linux 宿主机（如 VPS 或个人电脑）上常驻运行个人 AI 助理中枢。

### 核心特性
- **Agent-First 架构（以 Agent 为主，宿主机为辅）**：
  - 记忆系统（`SOUL.md`、`MEMORY.md`、`USER.md`、`memory/`）直接驻留在用户主目录（`~/`），透明可读可控；
  - 专属执行工作区位于 `~/workspace/`，隔离系统级隐藏文件，杜绝全局扫描造成的 Token 膨胀与误触风险；
- **跨平台独立守护运行**：
  - 基于轻量 Node.js（TypeScript），零外部数据库依赖；
  - 提供标准的后台启停脚本（`scripts/start.sh`, `scripts/stop.sh`）、systemd 单元模板（`lvtian-server@.service`）与 Windows 启动脚本（`start.bat`）；
  - 数据与凭据（`~/.config/lvtian/`）与代码及编译产物完全分离；
- **全天候长连接与状态机对账**：
  - 采用标准 WebSocket + HTTP（Bearer Token 鉴权），网络中立，支持局域网、Tailscale 虚拟内网、公网反代域名直连；
  - 手机断网、切后台或锁屏时，服务端底层任务持续执行并不中断；
  - 手机重新连上时，通过 `sync` 报文上报最后接收序号（`lastSeq`），服务端自动补齐离线期间的增量消息与最新执行状态。

## 2. 目录结构与关键代码

```text
server/
├── package.json               # 独立依赖与脚本 (Node >= 20)
├── tsconfig.json              # 服务端独立编译配置
├── dist/                      # 编译生成产物
├── src/
│   ├── index.ts               # 入口程序：解析参数、优雅停机、打印连接信息
│   ├── config.ts              # 配置管理：端口(3000)、Token生成、工作区解析
│   ├── protocol.ts            # 通信报文与状态契约 (与移动端同构)
│   ├── memoryManager.ts       # 记忆系统：管理 ~/SOUL.md, MEMORY.md, USER.md
│   ├── sessionManager.ts      # 会话中枢：管理序号(seq)、持久化、增量对账
│   ├── dshRunner.ts           # 引擎调度：驱动 dsh 循环、流式解析与中断控制
│   └── server.ts              # 网络中枢：HTTP 健康检查与 WebSocket 长连接管理
└── scripts/
    ├── start.sh               # Linux 后台守护启动脚本
    ├── stop.sh                # Linux 停止脚本
    ├── lvtian-server@.service # systemd 守护单元实例模板 (lvtian-server@<user>.service)
    └── start.bat              # Windows 启动脚本
```

## 3. 通信协议与报文规范

### 3.1 客户端上行报文 (ClientMessage)
- **认证**：`{ type: 'auth', token: string }`
- **对账**：`{ type: 'sync', sessionId: string, lastSeq: number }`
- **发消息**：`{ type: 'chat', sessionId: string, messageId: string, content: string }`
- **人工审批反馈**：`{ type: 'approval_response', approvalId: string, approved: boolean, reason?: string }`
- **停止执行**：`{ type: 'stop', sessionId: string }`
- **心跳**：`{ type: 'ping' }`

### 3.2 服务端下行报文 (ServerMessage)
- **认证结果**：`{ type: 'auth_result', success: boolean, serverInfo?: { version, workspace, assistantName } }`
- **对账结果**：`{ type: 'sync_result', sessionId, messages, taskState, currentSeq }`
- **受理回执**：`{ type: 'message_ack', messageId, seq }`
- **流式事件**：`{ type: 'event_chunk', seq, sessionId, messageId, delta, toolCall, status }`
- **审批申请**：`{ type: 'approval_request', seq, approvalId, prompt, toolName, params }`
- **状态同步**：`{ type: 'task_status', seq, sessionId, state, error }`
- **心跳回执**：`{ type: 'pong' }`

## 4. 移动端配合实现

1. **状态管理 (`src/store/useAssistantStore.ts`)**：
   - 存储服务地址与 Token（敏感凭据通过 `expo-secure-store` 加密保存）；
   - 维护会话消息队列与当前任务状态；
2. **长连接客户端 (`src/services/AssistantClient.ts`)**：
   - 单例模式，负责 WebSocket 自动重连（指数退避）、心跳保持、离线恢复；
   - 提供连接测试与剪贴板一键解析能力；
3. **主聊天页面 (`src/screens/ChatScreen.tsx`)**：
   - 未连接引导态（支持一键粘贴配置）；
   - 顶栏连接状态指示；
   - 用户与助理消息流（Markdown 渲染、工具活动状态标签）；
   - 人工审批卡片（同意/拒绝）；
   - 停止执行控制条；
4. **设置页 (`src/screens/AssistantConfigScreen.tsx`)**：
   - 提供服务地址、Token 输入、一键粘贴与即时联通性测试。
