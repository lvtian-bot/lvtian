# 任务只读展示

状态：2026-10-26 已实现下述列表、详情及按次结果读取；[PR #37](https://github.com/lvtian-bot/lvtian/pull/37) 已通过云端检查与 Codex 复审并合并，服务端部署与 Android production OTA 发布成功（适配 0.3.5 安装包）。真机视觉与交互验收尚未完成，发布成功不代表手机已下载并应用更新。

## 设计依据与取舍

- 用户提供的列表与详情截图：任务名称为主体，说明为辅助；详情上方说明工作，下方按时间展示动态。
- [DeepSeek Harness 官方指南](https://deepseek-harness.github.io/deepseek-harness/en/guide/schedule)：列表显示名称、频率与下次运行；二级详情拆分规则/记录，记录最新优先、每页 20 条；投递凭证不代表执行成功。官方未支持暂停或立即执行。
- [OpenAI ChatGPT Tasks](https://help.openai.com/en/articles/10291617-tasks-in-chatgpt) 与 [Anthropic Claude Cowork](https://support.claude.com/en/articles/13854387-schedule-recurring-tasks-in-claude-cowork)：集中任务入口、查看说明与计划、回看运行结果。仅借鉴信息层级，不照搬其暂停、编辑或其他绿天未提供的能力。
- 上述竞品依据为第一方文档，不将文档描述冒充桌面客户端视觉实测。绿天采用移动端熟悉的「任务列表 → 任务详情 → 执行动态」，而非桌面密集表格或后台验收面板。

## 列表

- 底部标签与页面标题统一为「任务」，共用 `tabs.todo` 文案。
- 只显示服务端 `status=active` 的任务；隐藏已结束记录，不删除后台任务或历史，不凭手机时间推测是否仍会调度。
- 每行：任务名称（最多两行）→ 简短频率及本地化时区名称 → 易读的下次执行时间。整行可点击进入详情，右侧方向提示，无复选框或虚假操作。
- 频率保留服务端保存的钟点；每天/每周/cron 按保存时区展示下一目标，一次性/间隔按设备时区展示。`scheduledAt` 直接取服务端，不计算新目标或手机本地调度。
- 首屏不堆完整指令、原始 ISO/UTC、内部状态与只读声明；以分隔线列表代替大卡片。下拉刷新，不放重复刷新按钮。
- 成功无开启任务显示「暂无开启的任务」，辅助说明可在主聊天交办。加载、读取失败、服务端未启用与成功空列表分开；刷新失败保留上次内容并提示可能过时。

## 详情

- 顶部返回与「任务详情」；正文完整展示名称、任务说明。
- 「运行时间」显示频率、下次执行、明确时区；自定义规则的原始 cron 仅在此展示，不在列表暴露表达式。
- 「执行动态」按原生保存顺序最新优先；时间显示实际投递 `deliveredAt`，不是计划时点，避免离线延迟触发时误导。
- 最新一条自动读取真实结果，默认显示三行可展开/收起；较早记录按需读取结果，不批量读取全部历史会话。历史成功返回空页但目录仍保留 `lastDelivery` 时，保留该最近回执及结果入口；非空原生历史不插入过时目录回执。
- 每条结果按该条 `messageId` 请求，不把最近一次结果套到历史记录。若该次保存的指令与当前说明不同，展示当次快照；缺失快照不拿当前说明替代旧指令。
- 每页 20 条，加载更早记录追加、按消息标识去重，不按客户端时钟排序。游标失效从第一页刷新，网络失败重试原失败页。旧记录清理提示仅在到达最后一页且服务器明确标记时出现。
- 记录与结果分别加载/失败/重试；结果缺失明确提示，不填造摘要。详情下拉先刷新目录，成功回读更新名称、说明、规则、下次执行并重新加载记录及同次结果；目录失败在详情提示可能过时并允许重试，不以历史刷新掩盖过时计划。回前台或连接恢复也刷新同次结果，不能让待确认结果永久滞留；刷新同一任务保留详情。身份切换、任务不再开启或离开页面时关闭详情并取消读取。

## 状态语义

- active/inactive 是调度状态，不是工作成功/失败；一次性任务投递后不再排程，不能据此称为已完成。
- 只有投递记录、尚未读取执行事实时显示「已触发」，无成功绿点；仅 `ended + endReason=completed` 显示「已完成」。明确 `failed/error` 显示「执行失败」，其他终态显示未确认完成；未终态或事实不完整显示尚未确认执行结果。
- 不根据持久化开放 turn 伪造实时「执行中」「等待审批」。颜色只辅助，不代替文字。
- 只显示所选投递对应 turn 的 assistant 可见文本，不显示系统上下文、思考或工具 schema。截断如实提示。时间线日期为投递时间，不声称精确的执行完成时刻。

## 边界与接口

- App 只读，不提供新建、重命名、编辑、删除、标记完成、暂停或立即运行，不追加主聊天通知或系统推送，不接入 Google Tasks；不放空的更多菜单。
- 创建和管理仍由主聊天原生工具承担，App 不是执行中枢。
- 权威规则及结果归原生宿主，位置见 [架构与接口](自动任务架构与接口.md)。App 使用既有鉴权 GET `/api/tasks`、`/api/tasks/:id/history`、`/api/tasks/:id/result?messageId=...`。
- 按次结果仅允许读取该任务原生目录/历史中证实归属的消息。历史已清理、消息属于同会话其他任务等情形返回不可用，不回退最新结果。旧服务端忽略参数并回传其他次结果时，客户端拒绝。
