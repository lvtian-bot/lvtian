# 系统文件与在线网盘架构

> 核心设计定位：直连独立服务端真实文件系统，云盘文件纯在线流式轻度操作。

---

## 1. 核心定位与设计决策

随着绿天接入跨平台独立服务端（Linux VPS / Windows PC），文件管理体系经历了核心升级：

1. **系统文件（主入口）**：
   - 移动端经底部「我」Tab 的“系统文件”入口进入 `ServerFileScreen`（注册于根导航 `RootStackParamList`），直连独立服务端 API。
   - 默认进入服务端实例的用户主目录（`os.homedir()`），适配跨平台（Linux、Windows）路径规范。
   - 支持多层级目录进入、返回、刷新、文本与 Markdown 预览以及任意文件下载调起系统原生分享打开。

2. **云盘文件纯在线化（独立入口）**：
   - 云盘文件经「我」页的“云盘文件”独立入口进入 `CloudNoteScreen`；系统文件页内不再保留云盘跳转按钮，一个业务一个入口。
   - 彻底剥离旧版全量本地沙盒缓存、影子基准副本和复杂的双向离线冲突队列。
   - 遵循“联网即用、按需获取”的纯在线模式，直接调用 WebDAV 协议拉取目录树与文件正文。

3. **统一预览与轻度编辑**：
   - 无论是服务端成果文件还是云盘中的 Markdown 笔记，均复用统一的 `PreviewScreen` 与 `EditorScreen`。
   - 保留成熟的 CodeMirror 6 嵌入式编辑器，支持文本查看与轻度修改。
   - 保存时在线直接覆盖回原位置（服务端保存采用 `mtime` 乐观锁防御并发冲突，网盘保存直接覆盖写入）。

---

## 2. 模块边界与架构职责

| 组件 / 文件 | 运行环境 / 宿主 | 职责边界 |
|------------|----------------|---------|
| `server/src/fileManager.ts` | 独立服务端 (Node.js) | 服务端文件系统封装：主目录解析、安全路径边界校验、目录遍历、正文读取、原子保存与流式下载 |
| `src/services/ServerFileService.ts` | 移动端服务层 | 封装移动端与服务端的 HTTP 文件管理接口，集成 Bearer Token 鉴权与超时熔断控制 |
| `src/screens/ServerFileScreen.tsx` | 移动端 UI 层 | 服务端目录浏览界面、Android 物理返回键层级退回、路径导航与文件操作分流 |
| `src/screens/CloudNoteScreen.tsx` | 移动端 UI 层 | 纯在线云盘文件浏览界面、文件扩展名与体积白名单防御、在线正文读取入口 |
| `src/screens/PreviewScreen.tsx` | 移动端 UI 层 | 纯在线/服务端/本地文件的统一只读预览渲染容器 |
| `src/screens/EditorScreen.tsx` | 移动端 UI 层 | 统一嵌入式编辑器容器，多源保存调度、草稿持久化与服务端乐观锁冲突拦截 |

---

## 3. 关键交互与边界防御规范

1. **目录切换防竞态**：
   - `ServerFileScreen` 与 `CloudNoteScreen` 均采用 `requestIdRef` 自增序列号机制。
   - 在用户快速点击切换或连续返回上一层时，晚到的旧请求自动丢弃，杜绝目录跳回与界面闪烁。
   - 系统文件按服务地址与令牌隔离浏览状态：任一变化时作废旧请求，清空路径、系统信息、列表、错误及加载状态；页面获焦时重新读取新身份的主目录，未获焦时等待下次进入再加载。旧请求的成功、失败或收尾均不得覆盖新身份的界面状态。
   - 每次返回系统文件页仍刷新当前目录；身份变化则不能沿用旧服务的子目录。配置页异步保存可能在离开配置页后才完成，不能假定身份变化时文件页必然失焦。排查与验证见 [加载状态问题记录](系统文件页加载状态问题记录.md)。

2. **大文件与非文本拦截**：
   - 文本预览采用严格的 `TEXT_EXTENSIONS` 扩展名白名单（支持 `.md`, `.markdown`, `.txt`, `.json`, `.js`, `.ts` 等代码与文本格式）。
   - 限制直接在内存中拉取文本预览的体积上限（<= 5MB）。
   - 针对非文本或超大文件，系统文件提供“下载并调起系统原生应用打开”通道；云盘文件予以弹窗拦截，杜绝 JS 堆内存 OOM 闪退。

3. **编辑草稿与生命周期隔离**：
   - 草稿 Key 采用 `source`（服务端 URL / 云盘路径 / 本地沙盒路径）强隔离前缀。
   - 本地文件模式下向下兼容历史草稿键名并自动迁移。
   - 用户确认恢复或丢弃草稿时，立即向 CodeMirror 6 WebView 发送 `SET_CONTENT` 消息，确保 UI 呈现与底层状态即时一致。

4. **文件下载**：
   - 移动端由 `NativeDownloadService` 使用新版原生下载任务，先写临时文件，成功后再替换目标，覆盖前备份；替换失败时尝试恢复旧目标。
   - 系统文件下载按 30 秒无进展超时，失败时显示通用下载失败提示，超时保留单独提示；新版接口不提供可直接判定的 HTTP 状态码。

5. **保存乐观锁**：
   - 服务端文件保存时携带读取时的原始 `mtime`，服务端对比修改时间。若在此期间被外部修改，返回 `409 Conflict`（错误代码 `PRECONDITION_FAILED`）拦截覆盖并提示用户。
