# 多云端问题记录

> 本文档记录多云存储接入、网络通信及跨厂商兼容性的问题档案与技术约束。

---

## 历史排查档案与技术约束

### 1. WebDAV 坚果云连接报 401 Unauthorized
- **现象**：用户在设置页面输入坚果云账号密码后，测试连接或同步提示 401 失败。
- **根因分析**：
  - 坚果云强制要求第三方客户端使用“应用专用密码 (App Password)”，若用户直接输入 Web 网页登录密码会被服务器拒绝。
- **必须保持的技术约束**：
  - 在云配置界面中，针对 WebDAV / 坚果云应明确展示提示文字，引导用户生成应用授权密码，并在错误捕获中细化 401 的提示文案。

### 2. 云存储上传大文件超时与网络挂死
- **现象**：当笔记中包含大量数据或网络较弱时，请求持续等待直至抛出 Unhandled Promise Rejection。
- **必须保持的技术约束**：
  - `TencentCOSProvider` 与 `WebDavProvider` 发起网络请求时，必须显式传入 20 秒超时设置，并在遇到网络不可达时优雅抛出特定错误码供上层 Stage 2 重试识别。
