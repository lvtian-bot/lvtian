# 编辑器架构与选型

> 本文档详细说明 MDNote 采用嵌入式 CodeMirror 6 编辑器的技术选型、构建流水线与 Bridge 通信协议。

---

## 1. 选型背景与核心考量

在移动端 React Native 中直接使用原生 `TextInput` 编辑复杂长篇 Markdown 存在两大业界痛点：
1. **换行与光标闪烁**：当文档较长且包含 Markdown 格式高亮时，受限于原生与 JS 线程间的异步通信，输入中文或长文换行极易出现光标漂移、视口跳动与闪烁。
2. **扩展性受限**：复杂的 Markdown 快捷工具栏、语法高亮折叠、代码块缩进难以高效实现。

MDNote 采用 **WebView 托管 CodeMirror 6** 的成熟方案：
- **Web 端独立排版**：所有文本输入、光标管理、撤销/重做历史、Markdown 语法解析由 WebView 内的 CodeMirror 6 完全在内部闭环，杜绝跨线程输入闪烁。
- **RN 端轻量交互**：React Native 容器仅负责标题栏操作、键盘避让辅助以及内容保存派发。

## 2. 源码结构与构建流程

### 2.1 目录组织
源码位于 `src/editor-web/`：
```text
src/editor-web/
├── index.html           # 页面模板
├── index.ts             # CodeMirror 6 初始化、扩展配置与消息监听
├── vite.config.ts       # Vite 构建配置 (使用 vite-plugin-singlefile)
├── generate-html.js     # 构建后注入脚本
└── editorHtml.ts        # 自动生成的 TypeScript 导出文件 (注入给 RN WebView)
```

### 2.2 双阶段构建命令
修改 `src/editor-web/` 中的任何文件后，必须执行：
```bash
npm run build:editor
```
该命令在 `package.json` 中的实际流水线为：
```bash
tsc --noEmit && vite build --config src/editor-web/vite.config.ts && node src/editor-web/generate-html.js
```
1. **阶段一**：Vite 将 TS/CSS/HTML 单文件打包至 `dist-web/index.html`。
2. **阶段二**：`generate-html.js` 读取打包产物并将其字符串转义，写入 `src/editor-web/editorHtml.ts`。
3. **阶段三**：`EditorScreen.tsx` 引入 `editorHtml` 并通过 `source={{ html: editorHtml }}` 加载。

## 3. Bridge 跨端通信协议

React Native 与 WebView 之间通过 `postMessage` 和 `window.ReactNativeWebView.postMessage` 交换 JSON 消息：

### 3.1 RN -> Editor (发送指令)
- `{ type: 'SET_CONTENT', payload: { content: string } }`：初始加载文档内容。
- `{ type: 'SET_THEME', payload: { theme: 'light' | 'dark' } }`：切换明暗主题。
- `{ type: 'GET_CONTENT' }`：主动请求当前最新内容。

### 3.2 Editor -> RN (事件回调)
- `{ type: 'CONTENT_CHANGE', payload: { content: string } }`：内容改动时防抖回传。
- `{ type: 'EDITOR_READY' }`：WebView 完成 CodeMirror 挂载，准备就绪。
- `{ type: 'LOG', payload: { level: string, message: string } }`：在 RN 控制台打印 WebView 内部调试日志。
