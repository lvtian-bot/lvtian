## 绿天适配

- 固定指令通过 DSH `systemPrompt.section` 注册，可编辑档案通过 `systemPrompt.context` 注册；内容不变时由 DSH 抑制重复快照。
- AGENTS.md 使用 DSH 原生发现与刷新，不重复加载；不自动创建、覆盖或修改已有 AGENTS.md。
- 个人档案仅对安装本插件的 ACP 根会话自动提供；子代理不自动注入。自动任务独立 web profile 不安装本插件。该范围限制不是文件系统沙箱，不能阻止已获权限的工具读取文件，也不能抹除主动 fork 继承的历史。
- 不声明 OpenClaw 专属工具、群聊、心跳、检索数据库或自动整理任务；使用实际可用的 DSH 文件工具。
- 隐私规则收紧为不记录凭据；工作区规范和人设文件的修改继续服从已有授权要求；不会指示模型擅自修改 AGENTS.md 或技能。
- 每日记忆由模型选择内容后写入；服务端不再自动截取回复，也不自动安排记忆整理任务。会话交接摘要保持独立。
- 现有用户文件和历史日记保留；缺失的基础档案仍由原初始化逻辑创建。IDENTITY.md 与 BOOTSTRAP.md 仅在用户已有文件时加载。

## 更新方式

升级上游时先核对固定提交与对应段落，逐项审阅工具、权限和运行机制差异，再修改适配指令和本说明；不得直接跟随上游主分支自动更新。
